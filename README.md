# ClassIQ

## Run the project

This is a static HTML, CSS, and JavaScript project. No build or package install is needed.

From the project folder, start a local server:

```powershell
py -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in a browser. The login and signup pages are at `/login/` and `/signup/`. Stop the server with `Ctrl+C`.

You can also open `index.html` directly, but a local server is recommended for JavaScript modules.

## Tools and libraries

- HTML, CSS, and JavaScript
- Tailwind CSS via CDN
- Poppins via Google Fonts
- Lenis for smooth scrolling
- Motion for page animations
- Python's built-in HTTP server for local preview

The CDN libraries and Google Fonts need an internet connection. Login, signup, and newsletter forms currently validate input in the browser; they are not connected to a backend.
